# 서부산 시장보고 HTML 프레젠테이션 V2 — 클라우드 작업 인계

## 목적

집과 ChatGPT Work 클라우드에서 동일한 HTML 프레젠테이션을 이어서 수정하기 위한 자급형 작업본이다. `index.html`과 `assets/`를 같은 구조로 유지하면 외부 네트워크 없이 실행할 수 있다.

## 실행 파일

- 편집 원본: `index.html`
- 로컬 자산: `assets/NotoSansKR-VF.ttf`, `assets/NotoSerifKR-VF.ttf`, `assets/west-busan-cycle.png`
- 인쇄 기준본: `서부산_체류형_관광_시장보고_V2.pdf`
- 사용자 조작 안내: `사용안내.txt`

## 확정된 10장 구성

1. 표지
2. 현황 — 대시보드 분석범위
3. 문제점 — 서부산·동부산 권역 격차
4. 문제점 — 서부산 4개 구별 병목
5. 비전 및 4대 정책방향
6. 3대 중점추진사업·9개 과제
7. 중점사업 1 — 데이터 기반 정책추진
8. 중점사업 2 — 체류기반 확충·민간투자
9. 중점사업 3 — 거점·콘텐츠 집중육성
10. 로드맵·시장 결정사항

## 핵심 데이터와 해석 제한

- 운영 DB 공개 발행 포인터 기준 물리적 숙박시설은 3,103개다.
- 확인 객실 합계는 67,944실이며 객실값 보유 시설은 2,234개, 전체의 72.0%다.
- 권역별 객실 보유율은 서부산 90.5%, 동부산 51.8%, 기타 부산 87.3%다. 따라서 객실 총량 비교는 자료 보유율을 같이 표시해야 한다.
- 관광수요는 부산 16개 구·군, 2025-08-01~2026-07-21의 355일 완전 관측을 사용한다.
- 객실 100실당 방문수요는 객실가동률이 아니라 현재 확인 객실 대비 수요압력 스크리닝 지표다.
- 건축물 연령은 사용승인일 기반이다. 실제 리모델링 상태를 의미하지 않으므로 현장조사 전에는 `노후 가능성` 또는 연령 확인 시설의 비율로 표현한다.
- 소비·3박 지표는 단위계약 검토 전까지 통화금액이나 실제 인원으로 표현하지 않고 `원천지표`로 표시한다.
- 교통 fact, OCC, ADR, RevPAR는 현재 발표 근거에 포함되지 않았다.
- 대시보드 결과는 자동 투자권고가 아니라 투자검토 우선지역·현장조사 후보군이다.
- 금융지원 700억원은 시비 보조금이 아니라 협약은행의 연간 대출공급 규모다. 최대 4%p 이차보전 시 서부산 연간 최대 시비 부담은 28억원이다.
- 금융지원, 활력지구, 빈집전환, 리버다이닝, 글로벌 빅탑 등은 확정사업이 아니라 검토안 또는 후보사업으로 유지한다.

## 편집 원칙

- 1920×1080 고정 16:9와 한 화면 한 메시지 원칙을 유지한다.
- 브라우저 좌우 키 이동, `F` 전체화면, `P` 인쇄 기능을 보존한다.
- 외부 CDN·웹폰트·원격 스크립트를 추가하지 않는다.
- 정책의 사실·분석결과·검토안을 시각적으로 구분한다.
- 수치 변경 시 화면 본문뿐 아니라 하단 출처·coverage·지표 정의도 함께 갱신한다.
- 디자인 변경은 사용자와 별도로 논의하기 전까지 구조와 데이터 논리를 우선한다.
