서부산 체류형 관광 활성화 및 민간투자 촉진방안
시장 보고용 HTML 프레젠테이션 V2 사용안내

구성: 현황·문제점(대시보드 분석) → 비전 → 3대 중점추진사업별 설명 → 로드맵, 총 10장

1. 실행
   - index.html을 Microsoft Edge 또는 Google Chrome으로 엽니다.
   - 인터넷 연결 없이도 폰트, 표지 이미지, 슬라이드 기능이 모두 표시됩니다.
   - 다른 PC로 옮길 때는 이 폴더 전체를 복사하십시오. assets 폴더를 분리하면 안 됩니다.

2. 발표 조작
   - 다음/이전: 오른쪽/왼쪽 방향키, PageDown/PageUp
   - 첫/마지막: Home/End
   - 전체화면: F 키 또는 브라우저의 F11
   - 인쇄: P 키 또는 Ctrl+P
   - 터치 화면: 좌우로 밀어 페이지 이동

3. PDF 백업
   - 서부산_체류형_관광_시장보고_V2.pdf는 10페이지 16:9 백업본입니다.
   - 현장 브라우저 환경에 문제가 있을 경우 PDF를 전체화면으로 열어 발표할 수 있습니다.

4. 주의사항
   - 금융조건, 활력지구, 빈집전환, 앵커콘텐츠는 자료 내 '검토안' 또는 사업화 단계 표기를 확인하십시오.
   - 700억원은 보조금이 아니라 협약은행 대출공급 규모이며, 시의 직접 재정부담은 이차보전액입니다.
   - 대시보드의 객실·건축연령 지표는 자료 보유율을 함께 확인해야 하며, 스크리닝 결과를 자동 투자권고로 해석하면 안 됩니다.
