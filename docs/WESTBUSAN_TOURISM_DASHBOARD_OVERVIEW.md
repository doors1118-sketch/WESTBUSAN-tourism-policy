# 부산 관광경제 활력 분석 대시보드 소개

## 1. 소개

부산 관광경제 활력 분석 대시보드는 부산의 방문수요를 체류·숙박·소비와 민간투자로 연결하기 위한 내부 정책지원 시스템이다. 단순 관광객 집계보다 **수요가 어디에 존재하고, 숙박 공급이 어디에서 부족하며, 어떤 투자를 먼저 검토해야 하는지**를 한 화면에서 확인하는 데 목적이 있다.

핵심 문제의식은 다음과 같다.

> 부산에 관광객이 없는 것이 아니라, 존재하는 관광수요가 서부산의 체류·숙박·소비로 충분히 전환되지 못하고 있다.

## 2. 주요 사용자와 활용 목적

- 부산광역시 관광정책 담당자와 관광혁신TF
- 구·군 관광·도시재생·건축·투자유치 담당자
- 숙박시설 개선, 신규 관광숙박, 빈집 전환과 콘텐츠 사업 검토자
- 정책보고서와 투자설명자료 작성자

정책현황 진단, 우선지역 선정, 사업 기획, 민간투자 설명자료 작성에 활용한다. 대시보드 순위는 투자 확정이나 인허가 판정이 아니라 후속 현장조사를 위한 1차 검토 신호이다.

## 3. 시스템이 답하는 세 가지 질문

### 관광 종합현황

방문·체류·소비·교통수요가 어디에서 얼마나 발생하는지를 권역과 구·군 단위로 비교한다.

### 공급 격차

숙박시설, 확인 객실, 시설 규모, 건물 연수, 인허가 업력, 관광숙박·외국인 수용 등록, 최근 신규 진입을 수요와 함께 비교해 공급 취약지역을 찾는다.

### 민간투자 유도

신규 공급, 기존 시설 리모델링, 빈집의 관광숙박 전환, 체류 콘텐츠 투자를 어느 지역에서 어떤 순서로 검토할지 근거를 제시한다.

## 4. 화면 구성

| 탭 | 주요 내용 | 정책 활용 |
|---|---|---|
| 종합현황 | 서·동·기타 부산의 핵심 KPI와 객실 공급구조 | 체류전환 격차의 빠른 파악 |
| 관광 종합현황 | 방문수요, 객실 대비 수요, 소비효율·3박 방문 원천지표 | 관광수요의 규모와 전환 가능성 확인 |
| 공급 격차 | 객실·시설 규모·노후도·업력·관광숙박·신규 진입 | 신규 공급과 시설개선 필요지역 진단 |
| 민간투자 유도 | 서부산 4개 구 우선순위와 투자유형 | 사업화·민간투자 검토 순서 설정 |
| 정책 인사이트 도출 | 검증된 발행지표를 근거로 한 AI 정책해석 | 보고서 초안과 정책회의 논점 정리 |
| 공간지도 | 500m 격자 기반 시설·수요·정책근거 | 공간적 집중과 주변 확산 확인 |
| 빈집 | 빈집 DB 적재와 제도·입지 검토 진행상태 | 관광숙박 전환 후보의 단계별 심사 |

## 5. 지표 해석 원칙

- 서부산·동부산·기타 부산을 같은 정의로 비교한다.
- 객실과 건축물 지표는 반드시 확인률과 함께 표시한다.
- 방문수요는 최신 완결기간의 외지인·외국인 방문자-인일을 사용한다.
- 소비효율과 3박 방문 지표는 원천기관 지수이며 원화 금액이나 실제 인원으로 표현하지 않는다.
- 체류시간과 교통 fact가 발행본에 없으면 `0`이 아니라 `자료 준비 중`으로 표시한다.
- 현재 시설 공개좌표가 승인되지 않은 경우 시설점을 임의로 만들지 않고 구·군 및 500m 격자를 사용한다.

## 6. 정책 인사이트 도출 기능

사용자가 버튼을 누르면 현재 발행본의 검증된 지표만 OpenAI 구조화 해석에 전달한다. 결과는 관광 종합현황, 공급 격차, 민간투자 유도 세 영역의 근거·한계·정책대안으로 나뉜다.

- 자유로운 사용자 프롬프트를 받지 않는다.
- 빈집 상세주소와 자격증명 등 민감정보를 모델에 보내지 않는다.
- 결과의 모든 정량 근거는 화면의 지표 ID와 다시 연결한다.
- 같은 발행본·권역 요청은 캐시해 비용과 응답시간을 줄인다.
- 외부 AI 장애나 일일 한도 초과 시 검증된 기본 규칙 해석을 제공한다.
- AI 결과는 정책검토 보조자료이며 법적·투자 판단을 대신하지 않는다.

## 7. 현재 데이터 기준과 한계

현재 발행본은 16개 구·군, 숙박시설 3,103개, 500m 격자 3,544개를 대상으로 한다. 방문수요는 최근 완결 355일을 사용한다. 서부산은 확인 객실 대비 방문 압력이 높지만 관광숙박·외국인 수용 등록과 최근 신규 진입이 동부산보다 낮다는 신호가 확인된다.

객실 확인률은 권역별로 차이가 있으므로 확인 객실 총량만으로 절대 공급을 단정하지 않는다. 체류시간과 교통 지표, 시설 단위 공개좌표는 후속 데이터 확보·승인 후 추가한다. 빈집 전환은 용도지역, 건축물 상태, 접도·소방·주차, 숙박업 유형별 인허가를 별도로 확인해야 한다.

## 8. 운영과 갱신

데이터 수집·품질검사·발행이 완료된 run만 대시보드가 읽는다. 지도와 정책 인사이트도 같은 발행본 ID에 결합하여 서로 다른 시점의 수치를 섞지 않는다. 기존 운영서비스와 관광 AI 서비스는 분리 배포하며, 새 기능 장애 시 관광 AI만 중지하거나 직전 UI release로 되돌릴 수 있다.
