# 낙동강 필지·법령근거 고도화 인수인계 (2026-08-29)

## 운영 반영 업데이트

- 2026-08-29 운영 서버에 필지도형·Korea-law-mcp·관광 AI 릴리스를 배포했다.
- 승인 대상 862필지 중 857필지의 도형을 연결했으며, 전체 PNU 대상 집합은 유지한다. 도형 미수집 5필지는 자동 좌표판정에서 `도형 미수집`으로 남기고 규제 없음으로 처리하지 않는다.
- `2026-08-29-v1` 내부 근거법령 레지스트리를 추가했다. 공간중첩과 사업행위에 따라 하천법·습지보전법·국가유산 관계법령·국토계획법·도시개발법·공원녹지법·건축법·관광진흥법의 조문과 공식 원문을 연결한다.
- MCP 응답에 공식 원문 URL이 없으면 해당 MCP 텍스트는 인용하지 않지만, 검증된 내부 근거법령으로 기본 정책해설을 계속 제공한다. 결정등급은 기존 서버 규칙을 유지한다.
- 모든 공개 해설은 인허가 처분 또는 관리청 공식의견을 대체하지 않는다는 고정 면책문구를 포함한다.

## 1. 목표와 판정 경계

- 지도 클릭 좌표를 승인된 낙동강 검토대상 필지의 지적도형과 교차하여 PNU로 자동 연결한다.
- 하천·환경·국가유산·도시계획·공원 중첩과 기존 결정규칙이 산출한 등급은 서버의 결정론적 판정값으로 유지한다.
- Korean Law MCP는 관련 법령·행정절차의 공식 원문 근거를 찾고 AI 설명에 인용하는 보조수단이다. MCP나 생성형 AI가 `원칙적 제한`, `관리청 협의 전제 검토`, `자료 미확인` 등급을 변경할 수 없다.
- 이 기능은 1차 정책검토이며 인허가 처분, 관리청 공식의견, 개별 고시 적용, 사업성 검토를 대체하지 않는다.

## 2. 구현된 구성

1. `sql/048_nakdong_parcel_geometry.sql`
   - 필지도형 동기화 실행, 불변 스냅샷, 현재 발행 포인터를 분리한다.
   - `matched`뿐 아니라 `not_found`, `provider_error`, `invalid_response`도 보존하여 수집 실패를 규제 없음으로 오인하지 않게 한다.
2. `westbusan.river_regulation.geometry`
   - 발행된 Polygon/MultiPolygon을 STRtree로 색인한다.
   - 클릭 결과를 `matched`, `boundary_ambiguous`, `scope_not_published`, `catalogue_unavailable`, `provided`로 구분한다.
3. `westbusan nakdong-parcel-geometry-sync`
   - 승인된 PNU 목록을 입력받아 VWorld 연속지적도 `LP_PA_CBND_BUBUN`을 PNU별로 조회하고 하나의 스냅샷으로 원자 발행한다.
4. `GET /tourism/api/regulations/point`
   - PNU를 전달하지 않아도 발행 지적도형 안의 좌표이면 PNU를 자동 해석하고 필지 토지이용 속성을 결합한다.
5. `POST /tourism/api/regulations/insight`
   - 공간판정, 필지해석 상태, 법령근거 해시를 묶어 정책해설을 생성·캐시한다.
   - AI 출력 스키마에 결정등급 필드가 없어 모델이 판정값을 덮어쓸 수 없다.
6. `westbusan.tourism_ai.legal_mcp`
   - `127.0.0.1` MCP만 허용하고 `legal_research`의 두 승인 task만 호출한다.
   - 법령응답은 별도 DuckDB에 24시간 저장하며 공식 법령 도메인 URL만 공개 응답에 포함한다.
7. 지도 UI
   - 필지 자동해석 상태를 표시한다.
   - 사용자가 `AI 정책 인사이트`를 눌렀을 때만 서버 해설을 요청한다.
8. 운영 격리
   - MCP는 전용 systemd 계정과 loopback `127.0.0.1:18082`로만 실행하며 Nginx에 MCP 경로를 공개하지 않는다.
   - 공개 Nginx에는 제한된 정책해설 POST 경로만 추가한다.

## 3. 검증 상태

- 신규 필지도형·MCP·API·OpenAI 스키마·프런트엔드·운영구성 영향범위 테스트: 56건 통과.
- 기존 CLI 테스트: 36건 통과(필지도형 동기화 무자격증명 차단 포함).
- JavaScript `node --check`: 통과.
- 변경 파일 Ruff 검사와 `git diff --check`: 통과.
- 전체 저장소 `pytest -q`는 약 12분 시점 6% 진행으로 예상 소요가 수 시간이라 중단했다. 따라서 전체 회귀 통과로 표시하면 안 된다.
- 내부 근거법령 레지스트리 추가 후 규제·필지·국가유산·MCP·AI API·프런트엔드·운영구성 영향범위 테스트 104건을 다시 실행해 통과했다.

## 4. 운영 잔여 제약

1. 승인 대상 862필지 중 5필지는 VWorld 연속지적도 응답이 반복해서 `invalid_response`를 반환했다. 이 필지는 발행 대상에서 제외하지 않고 도형 미수집으로 표시한다.
2. Korea-law-mcp `legal_research`는 동작하지만 현재 응답에 공식 원문 URL이 없다. 따라서 해당 MCP 텍스트는 공개 해설 근거에 포함하지 않고, 내부 근거법령 레지스트리만 사용한다.
3. 과거 적용 마이그레이션 8건은 현재 소스와 체크섬 불일치가 있어 일반 `Database.migrate()`가 차단된다. migration 048은 운영 DB 백업 후 별도 트랜잭션으로 적용됐다. 과거 마이그레이션 파일을 추가 수정하면 안 된다.
4. 좌표가 두 필지 경계에 정확히 놓이면 PNU를 임의 선택하지 않고 `boundary_ambiguous`로 닫힌다. 도형 미수집·발행범위 밖도 규제 없음이 아니다.
5. 영향범위 테스트 104건은 통과했지만 저장소 전체 테스트를 이번 릴리스에서 다시 실행한 것은 아니다.

## 5. 운영·롤백 확인

1. 대시보드와 관광 AI는 버전별 release 디렉터리를 만들고 `current` 심볼릭 링크를 원자적으로 전진한다.
2. Korea-law-mcp는 전용 계정과 격리된 Node.js 20 런타임을 사용하며 `127.0.0.1:18082`에만 바인딩한다. 공개 Nginx에는 MCP 자체 경로를 만들지 않는다.
3. 관광 AI는 `127.0.0.1:18081`에서 실행하고 공개 Nginx에는 제한된 정책해설 POST 경로만 제공한다.
4. 배포 전후 `nginx -t`, systemd 활성상태, `/healthz`, 관광·투자·빈집·낙동강 지도 HTTP 200을 확인한다.
5. 정책해설은 `deterministic_grade`, `legal_evidence_source`, `legal_bases`, 공식 법령 URL과 고정 면책문구를 확인한다. AI 사용 전후 결정등급이 달라지면 즉시 롤백한다.

## 6. 공개·보안 원칙

- `LAW_OC`, MCP access token, OpenAI key, VWorld key, SSH 개인키는 Git·브라우저·API 응답·인계문서에 포함하지 않는다.
- 브라우저 입력으로 MCP URL, 도구명, API key를 바꿀 수 없다.
- 법령 MCP 결과에 공식 원문 URL이 없으면 해당 MCP 텍스트를 인용하지 않는다. 검증된 내부 근거법령이 있으면 `legal_evidence_source=curated_registry`로 기본 정책해설을 제공하고, 근거법령도 없으면 `legal_evidence_status=unavailable`로 처리한다.
- 캐시 재사용 조건은 좌표·행위·PNU·공간 스냅샷·법령응답 해시·모델·프롬프트 버전이 모두 같은 경우뿐이다.
