# 교통·관광지 기반 투자·빈집지도 고도화 설계

- 작성일: 2026-08-25
- 대상 서비스: `https://busanproduct.co.kr/tourism/`
- 상위 설계: `docs/superpowers/specs/2026-08-21-tourism-investment-opportunity-map-design.md`
- 상태: 사용자 승인 범위의 보완 설계

## 1. 목적

투자정보 지도와 빈집 지도에 교통 유입과 관광지 접근 근거를 같은 발행 스냅샷으로
결합한다. 사용자는 다음 질문에 답을 얻어야 한다.

1. 어느 읍면동으로 대중교통 이용이 실제 유입되는가?
2. 숙박시설·빈집 후보에서 역·정류장·관광지까지 얼마나 가까운가?
3. 교통·관광 접근성이 있으나 숙박 공급이 부족한 생활권은 어디인가?
4. 빈집의 필지 연속성·면적과 접근성을 함께 볼 때 거점개발을 우선 검토할 곳은
   어디인가?

교통 OD는 관광객만을 식별하지 못한다. 따라서 `관광객 수`가 아니라
`대중교통 유입량` 또는 `교통 접근수요`로 표시한다. 자치구 방문수요를 읍면동 실측치로
표현하지 않는다.

## 2. 공통 발행 스냅샷

두 지도는 서로 다른 임시 JSON을 사용하지 않는다. 품질 승인된 하나의 접근성
스냅샷에서 다음 공개 투영을 생성한다.

- `transport_dong_month`: 월·도착 읍면동별 타동 유입, 타구 유입, 유출, 순유입
- `transport_hub_month`: 역·정류장별 승하차 또는 이용량과 기준월
- `tourism_poi_current`: 공식 좌표가 검증된 관광지의 명칭·분류·좌표·기준일
- `grid_access_current`: 500m 격자의 교통·관광 접근 근거
- `vacant_candidate_access_current`: 빈집 후보의 접근 근거와 후보 산식 적용 상태

모든 비율·점수에는 원값, 분모, 기준기간, 자료 커버리지를 함께 보존한다. 필수 입력이
누락되면 0점으로 대체하지 않고 `자료 미결합`으로 남긴다.

## 3. 원천과 의미

### 3.1 대중교통

- 국토교통부 일반버스·도시철도 OD 월별 이용량
- 국토교통부 정류장별 월별 이용량
- 부산교통공사 역·시간대별 승하차 자료(품질 승인 후 보완)

OD 기본 단위는 `월 × 출발 읍면동 × 도착 읍면동`이다. 같은 사람이 여러 번
이용하거나 환승하면 중복될 수 있고, 통행 목적을 알 수 없으며, 자가용·택시·항공·선박은
포함하지 않는다.

공개 지표는 다음과 같다.

- 타동 유입량: 도착 읍면동이 같고 출발 읍면동이 다른 통행량 합계
- 타구 유입량: 도착 자치구와 출발 자치구가 다른 통행량 합계
- 유출량: 출발 읍면동 기준 다른 읍면동 도착 통행량 합계
- 순유입: 타동 유입량 - 유출량
- 객실 100실당 타구 유입량: 타구 유입량 / 확인 객실 × 100

### 3.2 관광지

- 한국관광공사 국문 관광정보 `KorService2/areaBasedList2`
- 현재 발행된 연관 관광지 코드·명칭·순위
- 좌표 검증과 행정구역 확인을 위한 VWorld

공식 경위도가 부산 경계 안에 있고 행정구역이 일치하는 관광지만 게시한다. 음식점과
숙박업소는 관광지 레이어와 분리하고, 기본 관광지 접근성 산식에는 관광지 분류만 넣는다.

## 4. 접근성 지표

### 4.1 투자정보 지도

500m 격자와 1km 생활권에 다음 지표를 계산한다.

- 반경 1km 관광지 수와 가장 가까운 관광지 직선거리
- 반경 1km 역·정류장 수와 가장 가까운 교통거점 직선거리
- 해당 읍면동 타동·타구 대중교통 유입량
- 확인 객실 100실당 타구 대중교통 유입량
- 관광지·교통 접근성 대비 숙박공급 부족 신호

관광지·교통 접근성은 수요 자체가 아니라 입지 여건이다. 숙박공급 부족 결론은 방문수요,
객실 공급, 교통 유입 가운데 최소 두 축이 있고 기준기간이 명시된 경우에만 제시한다.

### 4.2 빈집 지도

빈집 전수 위치와 A형 연속필지, B형 일정 규모 단독필지, C형 북구 보완후보를 유지한다.
접근 근거가 서부산 4개 구 전체 후보에 동일 기준으로 확보되면 다음 가중치로 별도
`접근성 보완순위`를 계산한다.

- 필지 연속성·개발면적 45%
- 교통 접근성 20%
- 관광지 접근성 20%
- 자치구 방문수요 15%

한 축이라도 비교대상 전체에서 누락되면 기존 후보 순서를 바꾸지 않고 거리·이용량만
근거로 표시한다. 토지이용·소유권·접도·안전·소방·주차·위생·사업성은 별도 실사사항이다.

## 5. 화면

### 5.1 투자정보 지도

기존 레이어에 `대중교통 유입`, `교통거점 접근성`, `관광지 접근성`,
`접근성 대비 숙박공급 격차`를 추가한다. 관광지와 교통거점은 실제 좌표 마커로 표시하고,
선택 시 명칭·분류·기준일 또는 이용량·기준월을 보여준다.

선택 지역 상세에는 타동 유입, 타구 유입, 가장 가까운 역·관광지, 반경 1km 관광지 수,
확인 객실 100실당 타구 유입량을 표시한다. AI 해석에는 구조화된 동일 근거만 전달한다.

### 5.2 빈집 지도

`빈집 전수현황`, `개발후보`, `교통거점`, `관광지`를 독립 레이어로 둔다. 후보를 선택하면
필지 수·연속성·면적과 함께 가장 가까운 역·관광지, 이용량, 자치구 방문수요의 공간 단위를
표시한다. 상세 지번은 현재 내부직원 공유 범위에서 표시하되 공개범위 변경 시 별도
접근통제를 적용한다.

## 6. 품질·배포 게이트

- 교통 지표는 현재 core 발행 run의 `transport` membership이 1건 이상일 때만 게시한다.
- 관광지는 공식 좌표·부산 경계·행정구역 일치 검증을 통과한 행만 게시한다.
- 원천 행 합계와 읍면동 집계 합계가 일치해야 한다.
- 동일 관광지·거점 중복은 공식 식별자와 좌표 기준으로 제거한다.
- 지도 번들의 파일 수·행 수·체크섬을 manifest에 묶는다.
- 투자지도와 빈집지도는 동일 `access_snapshot_id`를 표시한다.
- 배포 전후 기존 공개 서비스와 관광·지도 URL의 HTTP 200을 확인한다.
- 실패한 수집·결합·번들은 현재 운영 pointer를 교체하지 못한다.
