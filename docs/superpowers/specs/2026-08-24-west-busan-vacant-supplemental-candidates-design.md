# 서부산 빈집 단독개발·숙박전환 예비후보 설계

## 목표

현행 빈집 지도는 지적 경계가 직접 접한 3필지 이상의 연속필지군만 거점개발
후보로 표시한다. 이 물리적 거점 기준은 유지하되, 후보가 4개에 그치는 점을
보완하기 위해 일정 규모 이상의 비연속 단독주택형 빈집 필지를 별도
`단독개발·숙박전환 예비후보`로 최대 6개 표시한다.

## 후보 유형

- A형 `연속필지 거점개발 후보`: 기존 기준 그대로 3개 이상 서로 연결된 PNU
  구성요소이다. 물리적 연속성이 확인된 거점개발 후보이다.
- B형 `단독개발·숙박전환 예비후보`: 연속필지군에는 속하지 않지만 검증된
  지적필지 면적과 주택유형 기준을 통과한 단일 PNU이다. 거점개발 후보라고
  부르지 않으며, 숙박전환·단독개발의 예비검토 대상이다.

## B형 적격 기준

1. 서부산 4개 구(강서구·북구·사상구·사하구)에 소재한다.
2. 현재 A형 연속필지군의 구성 PNU가 아니다.
3. VWorld 지적필지 조회가 `matched`로 검증된 유효 Polygon/MultiPolygon이다.
4. 해당 PNU의 현재 빈집 원문 주택유형이 모두 `단독주택`이다. 공동주택·연립·
   다세대의 개별 호수는 필지 전체 취득 가능성이 확인되지 않으므로 제외한다.
5. EPSG:5179로 투영해 계산한 지적필지 면적이 300㎡ 이상이다. 300㎡는 현재
   발행본의 비연속 단독주택형 빈집 필지 P90(약 252.9㎡)을 보수적으로 반올림한
   운영상 1차 선별선이며, 법적·사업성 기준이 아니다.
6. 전역 상위 최대 6개를 표시하며 자치구별 강제 할당은 하지 않는다.

## 정렬과 데이터 가용성

B형은 현재 확보 가능한 근거만으로 다음 순서로 정렬한다.

1. 최근 발행 공간본과 동일 산식의 자치구 방문수요 점수(내림차순)
2. 검증 지적필지 면적(내림차순)
3. PNU(오름차순, 결정성 보장)

방문수요는 최근 355일 외지인·외국인 일평균을 확인 객실로 나눈 자치구 간
백분위 점수이다. 동·필지 단위 관광수요로 해석하지 않는다. 인근 관광지 거리와
교통 접근성은 현 빈집 발행본에 결합되어 있지 않으므로 0점 처리하지 않고
`자료 미결합`으로 표시한다. 따라서 B형 번호는 최종 투자 우선순위가 아니라
현재 가용근거 기준의 예비검토 순서이다.

## 화면과 번들

- 기존 `hubs.geojson`과 A형 목록·레이어를 유지한다.
- `standalone-candidates.geojson`을 추가하고 manifest에 해시·바이트를 결속한다.
- 사이드바를 A형과 B형 두 묶음으로 나누고 A1…A4, B1…B6처럼 유형을 번호에
  포함한다.
- A형은 파란 원형/면, B형은 금색 마름모/면으로 표시하고 색상 외에 모양·문자도
  달리한다.
- B형 선택 상세에는 검증 필지면적, 빈집 수, 주택유형, 자치구 방문수요 점수,
  관광지·교통 미결합 상태와 법적·권리·안전 검토 한계를 표시한다.
- 기존 주소 분석 API의 연속필지군 판정 의미는 변경하지 않는다.

## 제한사항

이 기능은 투자검토 예비후보 선별이다. 소유권·매도의사·접도·용도지역·건축물
구조안전·소방·주차·위생·사업비·객실가동률을 확인하지 않았고, 관광지·교통
자료가 결합되기 전에는 최종 투자 우선순위나 관광숙박 전환 가능 판정으로
표현하지 않는다.
